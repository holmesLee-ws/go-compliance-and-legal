# go-compliance-and-legal

기업 법무와 컴플라이언스를 AI 튜터와 함께 익히는 학습 워크스페이스입니다. 계약, 회사법과 지배구조, 공정거래·하도급·대리점·전자상거래, 청탁금지·반부패, 중대재해, 지식재산, 그리고 회사의 준법 프로그램을 다룹니다. 한국 법을 뼈대로 하고, 미국·영국·EU 법과 ISO 표준을 비교 축으로 씁니다.

정해진 강의 자료는 없습니다. 이 리포에는 커리큘럼의 큰 지도와 튜터의 행동 규칙만 있습니다. 도식과 비교표, 조사 자료를 조합한 HTML은 대화하면서 튜터와 함께 그 자리에서 만듭니다.

**학습용입니다. 실제 사안의 법률 자문이 아닙니다.** 진행 중인 분쟁이나 서명할 계약의 결론은 변호사와 확인하세요. 튜터는 그 사안을 생각하는 법을 연습하게 도울 뿐입니다.

## 시작하기

준비물은 Git, [GitHub CLI](https://cli.github.com)(`gh`), Claude Code 또는 Claude Desktop입니다. 비공개 리포이므로 먼저 GitHub에서 보낸 초대를 수락하고, 터미널에서 `gh auth login`으로 로그인합니다. 다른 설치는 필요 없습니다.

```bash
cd ~/Desktop
gh repo clone holmesLee-ws/go-compliance-and-legal
```

**Claude Code**

```bash
cd ~/Desktop/go-compliance-and-legal
claude
```

처음 열면 이 폴더를 신뢰하는지 묻습니다. 기본 선택은 「No, exit」이므로 Enter만 누르면 종료됩니다. **아래 화살표로 「Yes, I trust this folder」를 고른 뒤 Enter**를 누르세요. 그래야 학습 기록 저장과 법령 조회를 튜터가 묻지 않고 진행합니다.

**Claude Desktop**

Code 탭에서 데스크탑의 `go-compliance-and-legal` 폴더를 선택합니다. Chat 탭이 아니라 Code 탭이어야 튜터 규칙이 적용됩니다.

어느 쪽이든 「안녕」이라고 입력하면 시작합니다.

## 이렇게 진행됩니다

1. 왜 배우려는지, 지금 하는 일에서 법·계약을 얼마나 다뤄 봤는지 짧게 묻습니다. 그다음 영역마다 내 업무에 맞춘 짧은 상황 문제로 출발점을 찾습니다. 처음이면 이 단계는 생략합니다.
2. 모듈마다 먼저 사실관계 문제로 수준을 확인합니다. 이미 아는 내용이면 바로 넘어갑니다.
3. 필요한 부분은 튜터와 대화하고, 내 답을 반영한 HTML(판단 흐름, 당사자 관계도, 국내·해외 비교표)을 함께 만들어 가며 익힙니다. 모듈마다 체크리스트·규정 초안 같은 업무 문서를 만들어 봅니다.
4. 조문 번호와 시행일은 튜터가 국가법령정보센터 같은 공식 출처에서 그 자리에서 확인해 알려 줍니다. 확인하지 못하면 그렇다고 말합니다.
5. 튜터는 내 답을 보고 너무 빠른지, 보강이 필요한지, 지루한지 판단해 속도와 방식을 바꿉니다.
6. 다음에 다시 열면 기록을 읽고 복습 질문 하나로 이어갑니다.

언제든 그냥 말로 요청하면 됩니다. 「이건 넘어가자」, 「너무 어려워」, 「표로 보여 줘」처럼요.

| 명령 | 하는 일 |
|---|---|
| `/learn [모듈 또는 주제]` | 시작하거나 이어가기 |
| `/check [모듈 또는 영역]` | 빠르게 수준 확인하고 건너뛰기 |
| `/map` | 지금까지의 현황과 다음 모듈 |
| `/pace [너무 빠름·너무 느림·지루함·어려움]` | 속도와 난도 바꾸기 |

## 구성

| 위치 | 내용 |
|---|---|
| [curriculum/map.md](curriculum/map.md) | 커리큘럼 지도와 공식 출처 목록 |
| [CLAUDE.md](CLAUDE.md), [tutor/](tutor/) | 튜터의 행동 규칙 |
| `.claude/` | 명령과 권한 설정 |
| `learner-template/` | 학습 기록의 빈 양식 |
| `learner/` | 내 기록, 내 HTML, 내 문서 초안. 처음 시작할 때 생깁니다 |

`learner/`는 Git에서 제외되어 내 컴퓨터에만 남습니다. 그래서 `git pull`로 커리큘럼을 업데이트해도 기록이 충돌하지 않습니다. 컴퓨터를 옮길 때는 이 폴더를 직접 복사하세요.

## 회사 자료를 가져올 때

실제 계약서나 사내 규정으로 연습하고 싶으면 회사명·사람 이름·금액·계좌를 지우고 붙이세요. 튜터는 원문을 저장하지 않고 가린 요지만 기록하지만, 대화 자체는 Claude 서비스로 전송됩니다. 회사의 비밀 유지 규칙이 허용하는 범위에서만 쓰세요.

## 튜터가 쓰는 권한

튜터는 묻지 않고 내 학습 기록, `learner/studio`의 HTML, `learner/lab`의 문서 초안을 쓰고, 웹(법령·기준 기관)을 조사하고, 만든 HTML을 열 수 있습니다. 그 밖의 파일을 고칠 때는 평소처럼 허락을 구합니다. 웹 조사 때는 질문과 주소가 외부 서비스로 전달되므로, 민감한 정보는 대화에 넣지 마세요.
